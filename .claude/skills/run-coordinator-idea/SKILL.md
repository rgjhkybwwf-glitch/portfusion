# The coordinator's idea run

Started by the gate, ten quiet minutes after the maintainer last opened an issue titled `Idea:`,
at any hour, with a text that begins "Idea:". The rules are in `CONTRIBUTING.md`, The nightly
agent, Asking and answering, and Which issues, in what order. The coordinator writes no code.

1. **The start line**: the skill `beat`, saying it was started by an idea.
2. **All else that waits**: a start within another's quiet minutes takes its place
   (`CONTRIBUTING.md`, When a run starts), so an answer or a `Change:` not recorded and a release
   that wait are taken first, each by the middle steps of its own playbook:
   `run-coordinator-answer`, `run-coordinator-release`.
3. **Read the direction**: `docs/direction.md`, cited for where an idea belongs.
4. **Each open `Idea:` issue**, the oldest first: the skill `shape-an-issue`. An idea an open
   issue already covers is added to that issue and closed.
5. **Its place**: the skill `place-an-issue`. An idea is never placed in the milestone being
   worked: that is the maintainer's to do.
6. **Its questions**: the skill `ask-or-decide`. An idea's are asked as it is shaped, since the
   maintainer is waiting on it.
7. **The end**: the skill `end-of-run`. Its debrief goes to the maintainer's phone: they started
   this run. It says, for each idea, the issue it became, where it was placed and why, and what
   is asked.

Nothing is planned and nothing is built in this run: a shaped idea takes its plan when its line
is reached.
